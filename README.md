# PostgreSQL-project

An academic project that I did while learning PostgreSQL

## 1. Project Objective

This project focuses on using PostgreSQL to develop a relational database to organize Formula 1 teams to analyze their performance, financial information, driver and race attendance.

## 2. SQL Techniques used in this project

- Database & Table Creation
- Primary & Foreign Keys
- JOINS
- Aggregation
- Group By
- Subqueries
